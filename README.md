# Seasonal-Agriculture-Performance-Analysis

## About the Project

This project is an Exploratory Data Analysis (EDA) of agricultural data collected across different seasons.

The main idea of the project is to understand whether agricultural performance changes from one season to another. I looked at factors such as crop yield, production, profit, rainfall, temperature, water usage, crops, irrigation methods, and differences between states.

The analysis was done using Python and visualizations were used to identify the main patterns in the data.

## Problem Statement

Agricultural performance can change depending on seasonal and environmental conditions. However, it is difficult to identify these changes by looking at raw data alone.

This project aims to analyze the available agricultural data and find meaningful differences and relationships between seasons, agricultural factors, and crop performance.

## Objectives

* Understand and clean the agricultural dataset.
* Compare crop yield across different seasons.
* Compare production and profit between seasons.
* Study rainfall and temperature across seasons.
* Analyze water usage and irrigation methods.
* Compare crop performance under different seasons.
* Compare agricultural performance across states.
* Explore relationships between different factors and crop yield.
* Summarize the main findings from the analysis.
